Geopolitical Risk Watchlist

Real-time media sentiment and reputational risk monitoring. (AvgTone 7-day trailing).

Data Source: GDELT Project 2.0 DOC API — endpoints mode=timelinetone and mode=artlist. AvgTone is calculated as the average lexical sentiment of all articles mentioning the entity in the queried period. Theoretical range [-100, +100]; practical operating window between -10 and +10.

Architecture: A Netlify Scheduled Function (fetch-gdelt-scheduled) queries GDELT on rotation and saves the output to Netlify Blobs. The browser client exclusively requests /api/geopolitical-data (shared cache).
