Data Source: GDELT Project 2.0 DOC API — endpoints mode=timelinetone and mode=artlist. AvgTone is calculated as the average lexical sentiment of all articles mentioning the country. Theoretical range [-100, +100]; practical operating window between -10 and +10.

Architecture: A Netlify Scheduled Function (fetch-gdelt-scheduled) queries GDELT on rotation and saves the output to Netlify Blobs. The browser exclusively requests /api/geopolitical-data (shared cache).

Risk Methodology: Weekly delta compares the current 7-day trailing average with the previous 7 days.
